Generative Render Engine.

The engine's real job: take source material, synthesize it in a chosen style, and return a finished artifact. This demo drives the production Gen-Engine's actual contract — 15 artifact types, 8 synthesis styles, 4 PLK modes, destinations, and a provenance envelope — with the style guides and format directives quoted verbatim from the engine source.

How this demo works, honestly: the prompt below is assembled the way the production engine assembles it — a system block (style directive + format directive) and a user block (title, source, PLK mode). Production sends them as separate system/user messages; this demo concatenates them because the signed proxy takes a single text field. Synthesis runs live via the runtime; rendering, themes, and file export happen here in your browser. Production adds: tRPC export (html/json/markdown), server-sealed provenance (SHA-256 + model provenance), artifact routing to destinations, and native renderers for mermaid/mind-map/graph — this demo renders everything as styled markdown and only declares a destination. Audio, video, image, and PDF are content formats with dedicated Studio renderers, not export formats.
