Generative Render Engine.

The engine's real job: take source material, synthesize it in a chosen style, and return a finished artifact. Here you drive the same contract — style, artifact type, and PLK handling — that the production engine uses.

How this demo works, honestly: the synthesis prompt below is built with the engine's actual logic (style guides, artifact formats, PLK constraint) and sent to the live runtime through the signed proxy. Rendering to a styled artifact happens here in your browser. The production engine does this server-side and adds export formats (PDF, PNG, audio) — those aren't in this demo.
