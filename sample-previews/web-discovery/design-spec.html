3 · Retro-Diner Art Direction

The one-line brief: a 1962 roadside diner, redrawn in flat vector — chrome-red optimism, mustard-yellow neon, cream formica. Warm, not kitsch. The chicken is the hero; everything else is the tray it sits on.
  • Sunburst: reserved for the hero and the logo medallion. Yellow rays at ≤30% opacity on red — present but never loud enough to fight the headline. Constructed in SVG (12 rays at 30° intervals); no raster images anywhere.
  • Stripes: diagonal yellow/orange repeating stripes (45°, 14px bands) as section dividers only — the divider used between sections of this very document. Never behind text.
  • Logo badge: circular medallion — red field, yellow ring, cream chicken silhouette in SVG. Flat, two-tone, legible at 24px favicon size and at hero scale.
  • Imagery rule (absolute): no photos. All illustration is CSS/SVG. This is a constraint from brief §3, and it is also the aesthetic — the flatness is the brand.
  • No gradients on text. Ever. (AA contrast commitment — gradient text cannot guarantee a ratio.) Decorative gradients are avoided entirely; solid tokens only.
  • Voice of the copy: warm, courteous, immaculate — "the brothers" tone. Short sentences. The Caveat tagline is the wink; everything else is the handshake.

5 · Accessibility Notes

  • Contrast: WCAG 2.1 AA on all text. Verified pairings in §1.1 — every ratio re-checked against the final tokens (brown on cream 11.74, cream on red 6.43, brown on yellow 8.08, cream on red-dark 9.98). Orange is decorative-only: brown-on-orange (4.26) fails, so it never carries text.
  • Keyboard: skip-link → header → main → footer order; visible yellow focus ring on every interactive element (§1.5); Esc closes the mobile menu and returns focus; accordion is native <details>.
  • Forms: real <label> elements (never placeholder-only), errors announced via aria-describedby, focus moved to the first invalid field, success confirmed in a full panel.
  • Motion: no autoplay, no parallax. prefers-reduced-motion: reduce freezes all decorative animation (sunburst, hover lifts keep their end-state, no transitions).
  • Semantics: one h1 per page; landmark regions (header/main/footer/nav); decorative SVGs carry aria-hidden="true"; the chicken logo has an accessible name.
  • Touch & readability: 44px minimum targets (48px mobile); 16px minimum input font; line-length capped at ~68 characters for body copy.
