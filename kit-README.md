# Sample Deliverables Kit — README

**SAMPLE — every artifact in this kit is illustrative.** The client is **Los Pollos Hermanos**, a fictional restaurant chain from the TV series *Breaking Bad*. All names, prices, addresses, and findings are invented for demonstration. No real business data anywhere in this kit.

## What this is

This kit contains every client-facing deliverable from the web-build offering **except the build itself** — produced as if for a real engagement, so a prospect can see the quality level before committing. This is the proof behind the portfolio's comparison block: *don't take our word for the difference — count the artifacts.*

## File map → offering phase

| File | Phase | What it demonstrates |
|---|---|---|
| `discovery-findings.html` / `.pdf` | Discovery ($600) | Findings doc: goals, constraints, key findings with design impact, risks, recommended direction |
| `implementation-spec.html` / `.pdf` | Implementation spec | The build plan: scope, 5 phases, per-page build notes, technical approach, acceptance criteria, exclusions, timeline, handoff checklist |
| `design-spec.html` / `.pdf` | Design spec + theme package | The theme package: full token tables (rendered swatches), type specimens, spacing, component demos, art direction, responsive + accessibility notes |
| `page-contracts/01-home.md` … `04-contact.md` | Page contracts (package standard) | One contract per page: purpose, content modules, nav flow, conversions, editable regions, acceptance notes |
| `mock-boards/board-1-home-desktop.html` | Pre-sale (2 mock boards) | Home page concept at desktop width — the showpiece |
| `mock-boards/board-2-home-mobile-menu.html` | Pre-sale (2 mock boards) | Home at mobile width + Menu page at desktop — the showpiece, continued |
| `README-quickstart-sample.md` | Handoff | The README a client receives: quickstart, how to edit menu/locations, what not to touch, bounded support terms |
| `provenance.json` | Provenance envelope | The kit's own manifest: every file, its hash, the born stamp |

## How to use it

- **Send the whole zip** to a prospect after the free consultation, or link individual pieces.
- The **mock boards** are the opener — visual proof first.
- The **specs** are the closer — rigor proof for the careful buyer.
- The **README** answers the unspoken question: *"what happens after I pay?"*
